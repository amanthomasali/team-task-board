# Sprint 1 Backlog

**Sprint Goal:** Deliver core task tracking functionality so that the team can create, assign, and monitor sprint tasks.

**Sprint Dates:** 09/17/26 → 09/18/26

---

### Story 1

**Title:** Create and View tasks

**User Story:**
> As a team member, I want to create a new task with a title and description so that I can track work that needs to be done.

**Story Points:** 3
**Priority:** High
**Status:** To Do

**Acceptance Criteria:**
- [ ] User created a task with a title and description
- [ ] Task appears in the task list immediately
- [ ] Task is saved and persists after page reload

---

### Story 2

**Title:** Assign tasks to team members

**User Story:**
> As a project lead, I want to assign a task to a specific team member so that ownership of work is clear.

**Story Points:** 2
**Priority:** High
**Status:** To Do

**Acceptance Criteria:**
- [ ] User can select assignee from a dropdown of teammembers
- [ ] Assigning tasks show the assignee's name on the task card
- [ ] Assignee can be changed after initial assignment

---

### Story 3

**Title:** Update task status

**User Story:**
> As a team member, I want to update a task's status (To do/ In progress/ Done) so that the team can see current progress at a glance.

**Story Points:** 1
**Priority:** Medium
**Status:** To Do

**Acceptance Criteria:**
- [ ] User can change status via dropdown or drag and drop
- [ ] Status change is reflected instantly in the UI
- [ ] Status changes are logged with a timestamp
